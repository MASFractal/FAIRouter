# Начальные веса кандидатов из рейтингов арены и Artificial Analysis

**Дата измерения:** 2026-09-14. Полный снимок (152 серии, 3,4 МБ) забран командой
`python -m fai_router.benchmarks --save`, укороченный до 60 записей на серию лежит в
[data/benchmark-snapshot.json](../../data/benchmark-snapshot.json). Каталог OpenRouter взят тем же
днем: 445 моделей, из них 349 без вариантов `:batch`, `:free` и подобных.

## Зачем

Холодный старт роутера задавался одним числом на модель: баллом возможностей из каталога
(контекст, модальности, инструменты). Опорная задача у всех кандидатов была одна, поэтому до
первого обучения они различались только этим баллом и по типам задач не расходились вовсе.
Рейтинги оценивают модели по сериям, которые ложатся на признаки задачи: язык программирования,
отрасль, фактология по областям знаний, трудность, экспертность, длина диалога, тип бизнес-задачи.

## Источники

Открытого API без ключа нет ни у одного источника, зато оба отдают страницы сервером с данными
внутри: в кусках `self.__next_f.push([1,"..."])` лежит JSON. Обычного GET достаточно.

| Источник | Что берется | Серий | Строк |
|---|---|---|---|
| Арена, текст | все 29 категорий, кроме служебной exclude-ties: общая, Expert, 8 отраслевых, математика, следование указаниям, многоходовый диалог, творческое письмо, код, трудные запросы (два варианта), длинные запросы, 10 языковых | 28 | |
| Арена, код и поиск | frontend, fullstack, html, react, brand-marketing; поисковая арена | 6 | |

| AA всего | | **118** | 7 877 |

Рейтинг фактологии арены отдельной страницей не отдается. Статья арены описывает метод
(атомарные утверждения, проверка агентами с веб-поиском, доля фактологии 25% в итоговом
рейтинге), но переключатель веса работает в браузере: адрес `text/overall-factuality` отдает общий
рейтинг без контроля стиля, параметры адреса ничего не меняют. Поэтому фактология берется у AA:
доля ответов без выдумки (`omniscienceNonHallucination`) есть у 521 модели, по областям знаний у
30 передовых. Прежняя категория `search/overall-factuality` на деле была обычным поисковым
рейтингом и переименована в `arena:search/overall`.

## Как серии становятся замерами

`QualityPrior.FromMeasurements` строит вектор кандидата по парам «признаки задачи, замеренное
качество». `BenchmarkPrior` дает ему такие пары: каждой серии соответствует профиль задачи, а
качество равно доле оценки модели между худшей и лучшей в серии (лидер получает единицу).

Профили лежат в одном файле
[fai_router/data/benchmark_profiles.json](../../Python/fai_router/data/benchmark_profiles.json),
общем для обеих версий: Python читает его как данные пакета, C# как встроенный ресурс. 81 серия
описана 88 профилями. Спецификация задачи собирается слиянием: опорная задача, шаблон (код,
наука, математика, деловая работа, техника) и поправки профиля. Примеры:

| Серия | Профиль задачи |
|---|---|
| `arena:text/expert` | экспертность 0,9, трудность 0,6 |
| `arena:text/instruction-following`, `aa:ifbench` | пять явных ограничений |
| `arena:text/multi-turn` | четыре реплики пользователя |
| `arena:text/hard-prompts` | трудность 0,9 |
| `aa:non-hallucination` | опора на факты 0,9 |
| `aa:omniscience/law` | деловая работа, право, юридическое заключение, опора на факты 0,9 |
| `aa:swe-language/rust` | код на Rust |
| `aa:automation/sales` | продажи, коммерческое предложение, три правила |
| `aa:index/finance-and-accounting` | финансы, финансовый отчет, две таблицы, экспертность 0,7 |
| `aa:briefcase/analytical` | аналитический отчет и анализ данных |

Серии, которые на признаки задачи не ложатся, в снимке хранятся, но в прайор не идут: части
индексов, оформление Briefcase, сервисы AutomationBench (признака «какой сервис» у задачи нет, а
модели на странице только 30).

## Сопоставление имен

Имена в трех местах различаются: `anthropic/claude-haiku-4.5` в каталоге, `claude-haiku-4-5` на
арене, `claude-4-5-haiku-reasoning` у AA. `ModelNames.Canonical` снимает поставщика, вариант после
двоеточия, хвосты усилия, режима, даты и контекста и приводит старый порядок имени Claude у AA к
новому. Из нескольких вариантов одной модели берется тот, у которого больше голосов, а при равных
голосах самый короткий ключ, то есть вариант без суффиксов.

| Величина | Значение |
|---|---|
| Моделей каталога без вариантов | 349 |
| Нашлись на арене | 151 |
| Нашлись у AA | 182 |
| Нашлись хотя бы в одном источнике | **199** |
| Нашлись в обоих | 134 |
| Серий на найденную модель, медиана | 36 из 81 |

По поставщикам (хотя бы в одном источнике): Anthropic 15 из 15, Z.ai 14 из 14, Moonshot 7 из 7,
DeepSeek 10 из 15, OpenAI 42 из 60, Qwen 35 из 51, Google 17 из 29, Mistral 8 из 19. Не находятся
в основном модели, которых нет ни в одном рейтинге: картинки и звук, размерные варианты Qwen,
линейка `-pro` OpenAI, датированные сборки Mistral.

## Скорость и цена задачи

Скорость в каталоге не публикуется, и раньше каждый кандидат без своих замеров получал 50 токенов в
секунду. Теперь начальную скорость дает замер AA (`medianOutputTokensPerSecond`), он есть у 147
моделей каталога.

Прайс не знает, сколько модель потратит на рассуждение. Цена задачи у AA разложена на вход,
рассуждение и ответ, и доля рассуждения дает начальную поправку цены: задача дороже прайса
ответа в `1 / (1 − доля)` раз, не больше чем в 5 раз. Поправка есть у 23 моделей, у остальных
остается единица, а журнал заменяет ее своей, как только наберет цены ходов.

| Модель | Скорость, токенов в секунду | Поправка цены |
|---|---|---|
| claude-opus-5 | 51,2 | 1,18 |
| gpt-6-astra | 59,8 | 1,31 |
| deepseek-v4-pro | 81,3 | 1,42 |
| gemini-3.1-pro-preview | 112,1 | нет данных |

## Что прайор различает

Прогноз прайора (без обучения) на профилях четырех отраслей у четырех передовых моделей:

| Модель | Код | Проза | Право | Финансы |
|---|---|---|---|---|
| claude-opus-5 | 0,95 | 0,95 | 0,97 | 0,88 |
| gpt-6-astra | 1,01 | 0,92 | 0,98 | 0,94 |
| deepseek-v4-pro | 0,74 | 0,89 | 0,63 | 0,64 |
| gemini-3-flash-preview | 0,67 | 0,90 | 0,13 | 0,10 |

Класс модели прайор разводит уверенно, и профиль у каждой свой: `gemini-3-flash-preview` на прозе
почти вровень с флагманами, а в праве и финансах на порядок ниже, у `deepseek-v4-pro` проза
сильнее кода. Прогноз выше единицы у `gpt-6-astra` на коде: это не ошибка, прогноз линейный и
поверх лидерства в сериях кода и знания языков программирования.

## Проверка на стенде качества

В [model-quality-grid.md](model-quality-grid.md) три модели одного класса замерены на четырех типах
задач по форме ответа. Прогноз прайора на тех же типах задач (`Settings.TaskMean` пуст):

| Тип задачи | gemini-2.5-flash | gpt-4.1-mini | claude-haiku-4.5 | Прайор выбрал | Лучший по стенду |
|---|---|---|---|---|---|
| научный | 0,27 | 0,24 | **0,75** | claude-haiku-4.5 | claude-haiku-4.5 |
| детский | **0,40** | 0,38 | −0,35 | gemini-2.5-flash | gemini-2.5-flash |
| деловой | 0,61 | 0,30 | **0,71** | claude-haiku-4.5 | gpt-4.1-mini |
| технический | **0,59** | 0,56 | 0,44 | gemini-2.5-flash | claude-haiku-4.5 |

**Два совпадения из четырех**; одна арена не давала ни одного. Стенд мерит форму (объем,
разделы, стиль), а рейтинги мерят содержание и предпочтение людей, поэтому полного совпадения здесь
и не ждали. Проверка по содержанию на 16 бизнес-задачах описана в
[business-evaluation.md](business-evaluation.md).

## Смена размерности

Вектор спецификации вырос с 23 до 104 координат, полный вектор задачи с 25 до 111. Сохраненные
векторы другой длины не подходят: в MAS `RouterCandidateSource` их отбрасывает и кандидат стартует с
прайора рейтингов, в библиотеке `SqliteWeightsStore.Load` на другой размерности бросает исключение
по замыслу. Задачи без предмета сохранили прежние ненулевые координаты, поэтому косинусы между ними
и оценки судьи формы не изменились: у перечислений предмета первое значение разряда не имеет.
